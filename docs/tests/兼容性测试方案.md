## 2. 数据导出方案

### 2.1 导出方案

**使用mysqldump工具导出完整数据库**：这是最安全、最可靠的导出方式，不会影响线上服务的正常运行。

### 2.2 详细导出步骤

#### 步骤1：连接到远程MySQL服务器

```bash
# 在远程服务器上执行
mysql -h 10.3.0.15 -P 3306 -u liuchang -p
# 输入密码：dK8~yF7*e

# liuchang
# dK8~yF7*e
```


#### 步骤2：查看数据库结构

```sql
-- 查看所有数据库
SHOW DATABASES;

-- 查看oneapi数据库的表结构
USE oneapi;
SHOW TABLES;

-- 查看表结构详情
DESCRIBE users;
DESCRIBE channels;
DESCRIBE logs;
DESCRIBE abilities;
-- 查看其他重要表...
```

#### 步骤3：导出完整数据库

**推荐方案（安全导出）**：
```bash
# 导出完整数据库（包含结构和数据，不会影响线上服务）
mysqldump -h 10.3.0.15 -P 3306 -u liuchang -p \
  --single-transaction \
  --routines \
  --triggers \
  --events \
  --no-create-db \
  --set-gtid-purged=OFF \
  --databases oneapi > oneapi_backup_$(date +%Y%m%d_%H%M%S).sql
```

**两种导出方案的区别**：
- `--add-drop-database`：会在SQL文件开头添加DROP DATABASE语句，适合完全重建数据库
- `--no-create-db`：不包含DROP DATABASE语句，更安全，不会破坏现有数据库结构

**推荐使用`--no-create-db`方案**，这样即使意外执行也不会删除线上数据库。

#### 步骤4：导出配置文件和数据文件

```bash
# 导出应用配置文件
cp ./data/oneapi/config.json ./config_backup_$(date +%Y%m%d_%H%M%S).json

# 导出日志文件（可选）
tar -czf logs_backup_$(date +%Y%m%d_%H%M%S).tar.gz ./logs/

# 导出docker-compose配置
cp docker-compose.yml ./docker-compose_backup_$(date +%Y%m%d_%H%M%S).yml
```

#### 步骤5：下载文件到本地

```bash
# 在本地执行，从远程服务器下载文件
scp username@remote-server:/path/to/oneapi_backup_*.sql ./
scp username@remote-server:/path/to/config_backup_*.json ./
scp username@remote-server:/path/to/docker-compose_backup_*.yml ./
```

### 3.2 配置本地Docker环境

#### 步骤1：检查项目docker-compose.yml

项目根目录下已有docker-compose.yml文件，需要根据本地环境进行以下修改：

**主要修改点**：
1. **数据库配置**：将SQL_DSN改为本地MySQL连接
2. **容器名称**：避免与线上环境冲突
3. **端口映射**：确保本地端口可用

**修改示例**：
```yaml
# 在现有docker-compose.yml基础上修改
services:
  one-api:
    container_name: one-api  # 修改容器名称
    environment:
      - SQL_DSN=oneapi:123456@tcp(db:3306)/oneapi  # 使用本地MySQL
      - REDIS_CONN_STRING=redis://redis:6379
      # ... 其他配置保持不变

  redis:
    container_name: redis-local  # 修改容器名称
    ports:
      - "6379:6379"  # 确保端口可用

  db:  # 如果原配置中没有db服务，需要添加
    image: "${REGISTRY:-docker.io}/mysql:8.2.0"
    container_name: mysql
    ports:
      - "3306:3306"
    volumes:
      - ./data/mysql:/var/lib/mysql
    environment:
      MYSQL_ROOT_PASSWORD: 'OneAPI@justsong'
      MYSQL_USER: oneapi
      MYSQL_PASSWORD: '123456'
      MYSQL_DATABASE: oneapi        # 修改为oneapi
```

#### 步骤5：容错性配置

**重要**：系统已添加容错机制，确保在课件平台配置错误时不会导致OneAPI崩溃：

1. **配置验证**：系统会验证所有必需配置是否完整
2. **客户端验证**：API客户端会检查自身是否有效初始化
3. **自动回退**：配置错误时自动回退到默认身份解析器
4. **错误日志**：详细的错误日志帮助诊断问题

**容错行为**：
- 如果 `COURSEWARE_ENABLED=false`：使用默认解析器
- 如果 `COURSEWARE_BASE_URL` 或 `COURSEWARE_API_KEY` 为空：使用默认解析器
- 如果API客户端初始化失败：使用默认解析器
- 如果Redis未启用：使用默认解析器

#!/bin/bash
DATE=$(date +%Y%m%d_%H%M%S)
BACKUP_DIR="./backups"

# 备份数据库
docker exec mysql mysqldump -u root -p'OneAPI@justsong' one-api > $BACKUP_DIR/oneapi_local_$DATE.sql

# 备份配置文件
cp ./data/oneapi/config.json $BACKUP_DIR/config_local_$DATE.json

# 压缩备份文件
tar -czf $BACKUP_DIR/backup_local_$DATE.tar.gz $BACKUP_DIR/oneapi_local_$DATE.sql $BACKUP_DIR/config_local_$DATE.json

# 清理临时文件
rm $BACKUP_DIR/oneapi_local_$DATE.sql $BACKUP_DIR/config_local_$DATE.json

echo "Backup completed: backup_local_$DATE.tar.gz"
EOF

chmod +x backup_local.sh
