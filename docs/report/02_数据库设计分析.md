# One API 数据库设计分析报告

## 数据库概述

One API 项目支持多种数据库系统，包括 MySQL、PostgreSQL 和 SQLite。项目使用 GORM 作为 ORM 框架，实现了数据库的自动迁移和统一访问。

## 数据库配置

### 数据库选择逻辑
```go
func chooseDB(envName string) (*gorm.DB, error) {
    dsn := os.Getenv(envName)
    
    switch {
    case strings.HasPrefix(dsn, "postgres://"):
        return openPostgreSQL(dsn)
    case dsn != "":
        return openMySQL(dsn)
    default:
        return openSQLite()
    }
}
```

### 支持的数据库类型
1. **MySQL**: 生产环境推荐，性能优异
2. **PostgreSQL**: 功能丰富，支持复杂查询
3. **SQLite**: 开发和小型部署，零配置

## 数据表结构

### 1. 用户表 (users)

```go
type User struct {
    Id               int    `json:"id"`
    Username         string `json:"username" gorm:"unique;index"`
    Password         string `json:"password" gorm:"not null;"`
    DisplayName      string `json:"display_name" gorm:"index"`
    Role             int    `json:"role" gorm:"type:int;default:1"`
    Status           int    `json:"status" gorm:"type:int;default:1"`
    Email            string `json:"email" gorm:"index"`
    GitHubId         string `json:"github_id" gorm:"column:github_id;index"`
    WeChatId         string `json:"wechat_id" gorm:"column:wechat_id;index"`
    LarkId           string `json:"lark_id" gorm:"column:lark_id;index"`
    OidcId           string `json:"oidc_id" gorm:"column:oidc_id;index"`
    AccessToken      string `json:"access_token" gorm:"type:char(32);column:access_token;uniqueIndex"`
    Quota            int64  `json:"quota" gorm:"bigint;default:0"`
    UsedQuota        int64  `json:"used_quota" gorm:"bigint;default:0"`
    RequestCount     int    `json:"request_count" gorm:"type:int;default:0"`
    Group            string `json:"group" gorm:"type:varchar(32);default:'default'"`
    AffCode          string `json:"aff_code" gorm:"type:varchar(32);uniqueIndex"`
    InviterId        int    `json:"inviter_id" gorm:"type:int;index"`
}
```

**字段说明**:
- `Id`: 用户唯一标识
- `Username`: 用户名，唯一索引
- `Password`: 密码（加密存储）
- `DisplayName`: 显示名称
- `Role`: 用户角色 (0:访客, 1:普通用户, 10:管理员, 100:根用户)
- `Status`: 用户状态 (1:启用, 2:禁用, 3:已删除)
- `Email`: 邮箱地址
- `GitHubId/WeChatId/LarkId/OidcId`: 第三方登录标识
- `AccessToken`: 系统管理令牌
- `Quota`: 用户配额
- `UsedQuota`: 已使用配额
- `RequestCount`: 请求次数
- `Group`: 用户组
- `AffCode`: 邀请码
- `InviterId`: 邀请人ID

### 2. 令牌表 (tokens)

```go
type Token struct {
    Id             int     `json:"id"`
    UserId         int     `json:"user_id"`
    Key            string  `json:"key" gorm:"type:char(48);uniqueIndex"`
    Status         int     `json:"status" gorm:"default:1"`
    Name           string  `json:"name" gorm:"index"`
    CreatedTime    int64   `json:"created_time" gorm:"bigint"`
    AccessedTime   int64   `json:"accessed_time" gorm:"bigint"`
    ExpiredTime    int64   `json:"expired_time" gorm:"bigint;default:-1"`
    RemainQuota    int64   `json:"remain_quota" gorm:"bigint;default:0"`
    UnlimitedQuota bool    `json:"unlimited_quota" gorm:"default:false"`
    UsedQuota      int64   `json:"used_quota" gorm:"bigint;default:0"`
    Models         *string `json:"models" gorm:"type:text"`
    Subnet         *string `json:"subnet" gorm:"default:''"`
}
```

**字段说明**:
- `Id`: 令牌唯一标识
- `UserId`: 所属用户ID
- `Key`: 令牌密钥，唯一索引
- `Status`: 令牌状态 (1:启用, 2:禁用, 3:过期, 4:耗尽)
- `Name`: 令牌名称
- `CreatedTime`: 创建时间
- `AccessedTime`: 最后访问时间
- `ExpiredTime`: 过期时间 (-1表示永不过期)
- `RemainQuota`: 剩余配额
- `UnlimitedQuota`: 是否无限配额
- `UsedQuota`: 已使用配额
- `Models`: 允许的模型列表
- `Subnet`: 允许的子网

### 3. 渠道表 (channels)

```go
type Channel struct {
    Id                 int     `json:"id"`
    Type               int     `json:"type" gorm:"default:0"`
    Key                string  `json:"key" gorm:"type:text"`
    Status             int     `json:"status" gorm:"default:1"`
    Name               string  `json:"name" gorm:"index"`
    Weight             *uint   `json:"weight" gorm:"default:0"`
    CreatedTime        int64   `json:"created_time" gorm:"bigint"`
    TestTime           int64   `json:"test_time" gorm:"bigint"`
    ResponseTime       int     `json:"response_time"`
    BaseURL            *string `json:"base_url" gorm:"column:base_url;default:''"`
    Balance            float64 `json:"balance"`
    BalanceUpdatedTime int64   `json:"balance_updated_time" gorm:"bigint"`
    Models             string  `json:"models"`
    Group              string  `json:"group" gorm:"type:varchar(32);default:'default'"`
    UsedQuota          int64   `json:"used_quota" gorm:"bigint;default:0"`
    ModelMapping       *string `json:"model_mapping" gorm:"type:varchar(1024);default:''"`
    Priority           *int64  `json:"priority" gorm:"bigint;default:0"`
    Config             string  `json:"config"`
    SystemPrompt       *string `json:"system_prompt" gorm:"type:text"`
}
```

**字段说明**:
- `Id`: 渠道唯一标识
- `Type`: 渠道类型 (对应不同的AI服务提供商)
- `Key`: API密钥
- `Status`: 渠道状态 (0:未知, 1:启用, 2:手动禁用, 3:自动禁用)
- `Name`: 渠道名称
- `Weight`: 权重
- `CreatedTime`: 创建时间
- `TestTime`: 测试时间
- `ResponseTime`: 响应时间(毫秒)
- `BaseURL`: 基础URL
- `Balance`: 余额(美元)
- `BalanceUpdatedTime`: 余额更新时间
- `Models`: 支持的模型列表
- `Group`: 渠道组
- `UsedQuota`: 已使用配额
- `ModelMapping`: 模型映射
- `Priority`: 优先级
- `Config`: 配置信息
- `SystemPrompt`: 系统提示词

### 4. 能力表 (abilities)

```go
type Ability struct {
    Group     string `json:"group" gorm:"type:varchar(32);primaryKey;autoIncrement:false"`
    Model     string `json:"model" gorm:"primaryKey;autoIncrement:false"`
    ChannelId int    `json:"channel_id" gorm:"primaryKey;autoIncrement:false;index"`
    Enabled   bool   `json:"enabled"`

}
```

**字段说明**:
- `Group`: 用户组
- `Model`: 模型名称
- `ChannelId`: 渠道ID
- `Enabled`: 是否启用
- `Priority`: 优先级

**作用**: 定义哪些用户组可以使用哪些渠道的哪些模型，实现细粒度的权限控制。

## 索引设计

### 主要索引

1. **用户表索引**
   - `username` (唯一索引)
   - `access_token` (唯一索引)
   - `aff_code` (唯一索引)
   - `display_name` (普通索引)
   - `email` (普通索引)
   - 第三方登录ID索引

2. **令牌表索引**
   - `key` (唯一索引)
   - `user_id` (普通索引)
   - `name` (普通索引)

3. **渠道表索引**
   - `name` (普通索引)
   - `status` (普通索引)

4. **能力表索引**
   - `(group, model, channel_id)` (复合主键)
   - `channel_id` (普通索引)
   - `priority` (普通索引)

5. **日志表索引**
   - `user_id` (普通索引)
   - `(created_at, type)` (复合索引)
   - `(username, model_name)` (复合索引)
   - `channel_id` (普通索引)
   - `token_name` (普通索引)

```go
func Redeem(ctx context.Context, key string, userId int) (quota int64, err error) {
    err = DB.Transaction(func(tx *gorm.DB) error {
        // 查询兑换码
        err := tx.Set("gorm:query_option", "FOR UPDATE").Where("key = ?", key).First(redemption).Error
        if err != nil {
            return errors.New("无效的兑换码")
        }
        
        // 更新用户配额
        err = tx.Model(&User{}).Where("id = ?", userId).Update("quota", gorm.Expr("quota + ?", redemption.Quota)).Error
        if err != nil {
            return err
        }
        
        // 更新兑换码状态
        redemption.Status = RedemptionCodeStatusUsed
        err = tx.Save(redemption).Error
        return err
    })
    return redemption.Quota, err
}
```

## 总结

One API 的数据库设计具有以下特点：

1. **灵活性**: 支持多种数据库类型
2. **可扩展性**: 模块化的表结构设计
3. **高性能**: 合理的索引和缓存策略
4. **一致性**: 事务保证数据完整性
5. **可维护性**: 自动迁移和版本管理

数据库设计充分考虑了系统的业务需求，通过合理的表结构和索引设计，保证了系统的高性能和可靠性。
