# 多学校费用分别计算完整方案 - 最终合并版

## 文档概述

本文档是针对 One-API 系统的多学校费用分别计算需求的最终完整方案，融合了学科组扩展功能、智能模型选择功能和低耦合设计理念。本方案在保持原有系统完全兼容的基础上，实现了学校 → 学科组 → 老师的三级费用管理体系，并采用扩展日志表设计，确保系统升级的便利性和安全性。

**核心特性**：
1. 明确了各系统平台职责分工
2. 采用API调用方式获取学校/科组/用户信息
3. 设计了基于缓存的数据获取策略
4. 采用低耦合的扩展日志表设计
5. 简化系统架构，减少数据冗余和同步成本
6. **智能模型选择**：根据用户身份自动匹配相应模型
7. **多维度费用隔离**：学校级别和学科组级别的精细化费用管理

---

## 1. 业务需求分析

### 1.1 业务背景

**系统架构链路**：
- **课件制作平台**：核心数据源，维护用户、学校、学科组基本信息和用户模型偏好
- **Dify系统**：工作流管理系统，执行工作流
- **One-API系统**：大模型聚合中转系统，按学校/科组/用户隔离配额，
- **用户层级**：学校 → 学科组 → 老师，需要按学科组维度进行费用计算

**当前配置**：
```bash
# Dify系统配置
BASE_URL=http://api.hk33smarter.com/v1
APIKEY=sk-xxx

# One-API系统配置
渠道1：deepseek渠道 → deepseek-chat模型
渠道2：硅基流动 → Qwen2.5-VL-72B模型
```

### 1.2 核心需求

1. **学科组级别费用分离**：每个学科组的大模型使用费用独立计算
2. **老师到学科组映射**：通过 teacher_id 识别老师所属学科组
3. **多模型提供商支持**：每个学科组可采购不同的模型提供商
4. **自动模型选择**：根据学科组采购情况自动选择可用模型
5. **独立配额管理**：学科组间配额完全隔离，互不影响
6. **低耦合设计**：保持原有系统完全不受影响，便于未来升级
7. **用户-模型智能匹配**：根据用户身份（学校、学科组）自动匹配相应模型，对用户透明

### 1.3 技术约束

- Dify 只能通过 header 提供 user_id（实际为老师ID），无学校和学科组信息
- 不能在 One-API 为每个老师创建账号（用户量大）
- 需要保持 One-API 的高性能特性
- 尽量不改动课件制作平台和 Dify 的业务逻辑
- **数据维护唯一性**：避免在One-API中重复维护课件平台已有的数据
- **职责明确性**：各系统职责边界清晰，避免功能重叠
- **性能优先**：保持请求链路的高性能，减少延迟
- **最小代码改动**：尽量避免大规模修改开源项目代码

## 3. 改造后系统架构设计

### 3.1 低耦合设计原则

**设计目标**：
- 保留原有日志表结构不变
- 通过扩展日志表实现新功能
- 原有功能完全不受影响
- 便于未来系统升级和维护

**架构策略**：
```
原有系统（保持不变）           扩展系统（新增功能）
    │                           │
    ├── logs（原日志表）         └── extended_logs（扩展日志表）
    ├── users（原用户表）        
    ├── tokens（原令牌表）       
    └── channels（原渠道表）     
    │                           
    └─────── 通过log_id关联 ─────┘
```

### 3.2 数据获取策略

#### 3.2.1 初始化加载
```
One-API启动时 ──► 向课件平台查询基础数据 ──► 缓存到Redis
```

#### 3.2.2 动态查询
```
请求处理 ──► 检查Redis缓存 ──► 缓存命中：直接使用
                │
                └───────────► 缓存未命中：API调用课件平台 ──► 更新缓存
```

### 3.3 智能模型选择机制

#### 3.3.1 请求头字段说明
Dify系统向One-API系统传递以下关键字段：
- **X-User-ID**：用户ID，用于识别具体用户
- **X-Smart-Model-Selection**：智能模型选择开关，值为"true"时启用智能选择

#### 3.3.2 模型选择逻辑
```
请求到达 ──► 检查X-Smart-Model-Selection头
                │
                ├── 为"true" ──► 查询用户模型配置 ──► 配置存在：使用配置模型
                │                                    └── 配置不存在：使用请求模型
                │
                └── 为"false"或不存在 ──► 直接使用请求模型
```

#### 3.3.3 用户模型配置管理
- **配置维护**：由课件平台数据库维护用户模型偏好
- **数据获取**：One-API系统通过API调用获取用户配置信息
- **缓存策略**：采用Redis缓存提升性能，减少API调用频率
- **降级机制**：当无法获取用户配置时，自动降级使用请求中的原始模型

#### 3.3.4 学科组默认模型管理
- **学科组-模型映射**：每个学科组可配置默认使用的模型
- **自动模型选择**：基于学科组自动选择对应模型，无需修改Dify平台或课件平台
- **配置示例**：
  ```
  学校A - 学科组a (数学组) → deepseek-chat模型
  学校A - 学科组b (语文组) → Qwen2.5-72B模型
  ```
- **管理接口**：提供API接口用于设置和查询学科组默认模型

```go
// 获取用户模型配置（带缓存）
func getUserModelConfigWithCache(ctx context.Context, userID string) (*UserModelConfig, error) {
    // 1. 尝试从Redis缓存获取
    cacheKey := fmt.Sprintf("user_model_config:%s", userID)
    configStr, err := common.RedisGet(cacheKey)
    
    if err == nil {
        // 缓存命中，解析并返回
        var config UserModelConfig
        err = json.Unmarshal([]byte(configStr), &config)
        return &config, err
    }
    
    // 2. 缓存未命中，从课件平台API获取
    config, err := getUserModelConfigFromAPI(ctx, userID)
    if err != nil {
        return nil, err
    }
    
    // 3. 更新缓存
    configJson, _ := json.Marshal(config)
    _ = common.RedisSet(cacheKey, string(configJson), time.Hour*24)
    
    return config, nil
}

// 从课件平台API获取用户模型配置
func getUserModelConfigFromAPI(ctx context.Context, userID string) (*UserModelConfig, error) {
    url := fmt.Sprintf("%s/teacher/%s/model", config.CoursewarePlatformBaseURL, userID)
    
    req, err := http.NewRequestWithContext(ctx, "GET", url, nil)
    if err != nil {
        return nil, err
    }
    
    req.Header.Set("Authorization", fmt.Sprintf("Bearer %s", config.CoursewarePlatformAPIKey))
    
    client := &http.Client{Timeout: 5 * time.Second}
    resp, err := client.Do(req)
    if err != nil {
        return nil, err
    }
    defer resp.Body.Close()
    
    if resp.StatusCode != http.StatusOK {
        return nil, fmt.Errorf("API返回错误状态码: %d", resp.StatusCode)
    }
    
    var response struct {
        Success bool           `json:"success"`
        Data    UserModelConfig `json:"data"`
    }
    
    err = json.NewDecoder(resp.Body).Decode(&response)
    if err != nil {
        return nil, err
    }
    
    if !response.Success {
        return nil, fmt.Errorf("API返回失败")
    }
    
    return &response.Data, nil
}
```

```go
// 系统启动时加载基础数据
func InitializeSystemData() {
    // 1. 加载学校配额信息
    go loadSchoolQuotaData()
    
    // 2. 预热常用老师信息缓存
    go preloadFrequentTeachers()

// 加载学校配额数据
func loadSchoolQuotaData() {
    ctx := context.Background()
    logger.Infof(ctx, "开始加载学校配额数据...")
    
    schools, err := getAllSchoolsFromAPI(ctx)
    if err != nil {
        logger.Errorf(ctx, "加载学校数据失败: %v", err)
        return
    }
    
    for _, school := range schools {
        // 获取并缓存学校配额信息
        quotaInfo, err := getSchoolQuotaFromAPI(ctx, school.Id)
        if err != nil {
            logger.Warnf(ctx, "获取学校[%s]配额失败: %v", school.Name, err)
            continue
        }
        
        // 缓存学校配额信息
        cacheKey := fmt.Sprintf("school_quota:%d", school.Id)
        quotaJson, _ := json.Marshal(quotaInfo)
        _ = common.RedisSet(cacheKey, string(quotaJson), time.Hour*24)
        
        logger.Debugf(ctx, "已缓存学校[%s]配额信息", school.Name)
    }
    
    logger.Infof(ctx, "学校配额数据加载完成，共加载%d个学校", len(schools))
}

// 预热用户模型配置缓存
func preloadUserModelConfigs() {
    ctx := context.Background()
    logger.Infof(ctx, "开始预热用户模型配置缓存...")
    
    // 获取常用用户列表（可以从课件平台获取或使用配置的用户列表）
    frequentUsers, err := getFrequentUsersFromAPI(ctx)
    if err != nil {
        logger.Errorf(ctx, "获取常用用户列表失败: %v", err)
        return
    }
    
    for _, userID := range frequentUsers {
        // 获取并缓存用户模型配置
        config, err := getUserModelConfigFromAPI(ctx, userID)
        if err != nil {
            logger.Warnf(ctx, "获取用户[%s]模型配置失败: %v", userID, err)
            continue
        }
        
        // 缓存用户模型配置
        cacheKey := fmt.Sprintf("user_model_config:%s", userID)
        configJson, _ := json.Marshal(config)
        _ = common.RedisSet(cacheKey, string(configJson), time.Hour*24)
        
        logger.Debugf(ctx, "已缓存用户[%s]模型配置: %s", userID, config.ModelName)
    }
    
    logger.Infof(ctx, "用户模型配置缓存预热完成，共预热%d个用户", len(frequentUsers))
}

// 学科组默认模型管理
func GetSubjectDefaultModel(subjectId int) (string, error) {
    var subject SubjectMapping
    
    // 先从缓存获取
    cacheKey := fmt.Sprintf("subject_default_model:%d", subjectId)
    if model, err := cache.Get(cacheKey); err == nil && model != "" {
        return model.(string), nil
    }
    
    // 缓存未命中，从数据库获取
    err := DB.Select("default_model").
        Where("subject_id = ? AND status = ?", subjectId, 1).
        First(&subject).Error
    
    if err != nil {
        return "", err
    }
    
    // 写入缓存
    if subject.DefaultModel != "" {
        cache.Set(cacheKey, subject.DefaultModel, 30*time.Minute)
    }
    
    return subject.DefaultModel, nil
}

// 设置学科组默认模型
func SetSubjectDefaultModel(subjectId int, modelName string) error {
    // 更新数据库
    err := DB.Model(&SubjectMapping{}).
        Where("subject_id = ?", subjectId).
        Update("default_model", modelName).Error
    
    if err != nil {
        return err
    }
    
    // 更新缓存
    cacheKey := fmt.Sprintf("subject_default_model:%d", subjectId)
    cache.Set(cacheKey, modelName, 30*time.Minute)
    
    return nil
}
```

```go
// 扩展日志记录中间件
func ExtendedLogRecorder() gin.HandlerFunc {
    return func(c *gin.Context) {
        // 先执行后续中间件和处理器
        c.Next()
        
        // 检查是否需要记录扩展日志
        if shouldRecordExtendedLog(c) {
            go recordExtendedLog(c)
        }
    }
}

// 判断是否需要记录扩展日志
func shouldRecordExtendedLog(c *gin.Context) bool {
    // 只有在有学科组信息时才记录扩展日志
    subjectId := c.GetInt(ctxkey.SubjectId)
    teacherId := c.GetString(ctxkey.TeacherId)
    
    return subjectId > 0 || teacherId != ""
}

// 记录扩展日志
func recordExtendedLog(c *gin.Context) {
    ctx := context.Background()
    
    // 获取原日志ID（从响应头或其他方式获取）
    logIdStr := c.GetHeader("X-Log-ID")
    if logIdStr == "" {
        // 如果没有日志ID，可能需要通过其他方式获取最新的日志记录
        logIdStr = getLatestLogId(c)
    }
    
    if logIdStr == "" {
        logger.Errorf(ctx, "无法获取日志ID，跳过扩展日志记录")
        return
    }
    
    logId, err := strconv.Atoi(logIdStr)
    if err != nil {
        logger.Errorf(ctx, "日志ID格式错误: %s", logIdStr)
        return
    }
    
    // 构建扩展日志信息
    extendedInfo := &model.ExtendedLogInfo{
        SchoolId:    c.GetInt(ctxkey.SchoolId),
        SchoolName:  c.GetString(ctxkey.SchoolName),
        SubjectId:   c.GetInt(ctxkey.SubjectId),
        SubjectName: c.GetString(ctxkey.SubjectName),
        TeacherId:   c.GetString(ctxkey.TeacherId),
        TeacherName: c.GetString(ctxkey.TeacherName),
        GroupName:   c.GetString(ctxkey.Group),
    }
    
    // 记录扩展日志
    err = model.CreateExtendedLog(ctx, logId, extendedInfo)
    if err != nil {
        logger.Errorf(ctx, "创建扩展日志失败: %v", err)
    } else {
        logger.Debugf(ctx, "扩展日志记录成功: logId=%d, teacherId=%s, subjectId=%d", 
            logId, extendedInfo.TeacherId, extendedInfo.SubjectId)
    }
}
```

```go
// 获取学科组使用统计
func GetSubjectUsageStats(ctx context.Context, schoolId int, startTime, endTime int64) ([]SubjectUsageStats, error) {
    var stats []SubjectUsageStats
    
    query := `
        SELECT 
            el.subject_id,
            el.subject_name,
            el.school_id,
            el.school_name,
            COUNT(l.id) as request_count,
            SUM(l.prompt_tokens + l.completion_tokens) as total_tokens,
            SUM(l.quota) as total_quota,
            COUNT(DISTINCT el.teacher_id) as teacher_count,
            CASE 
                WHEN COUNT(DISTINCT el.teacher_id) > 0 
                THEN SUM(l.quota) / COUNT(DISTINCT el.teacher_id)
                ELSE 0 
            END as avg_quota_per_teacher
        FROM extended_logs el
        JOIN logs l ON el.log_id = l.id
        WHERE 1=1
    `
    
    args := []interface{}{}
    
    if schoolId > 0 {
        query += " AND el.school_id = ?"
        args = append(args, schoolId)
    }
    
    if startTime > 0 {
        query += " AND l.created_at >= ?"
        args = append(args, startTime)
    }
    
    if endTime > 0 {
        query += " AND l.created_at <= ?"
        args = append(args, endTime)
    }
    
    query += " GROUP BY el.subject_id, el.subject_name, el.school_id, el.school_name ORDER BY total_quota DESC"
    
    err := DB.WithContext(ctx).Raw(query, args...).Scan(&stats).Error
    return stats, err
}

// 获取学校使用统计
func GetSchoolUsageStats(ctx context.Context, startTime, endTime int64) ([]SchoolUsageStats, error) {
    var stats []SchoolUsageStats
    
    query := `
        SELECT 
            sm.school_id,
            sm.name as school_name,
            COUNT(l.id) as request_count,
            SUM(l.prompt_tokens + l.completion_tokens) as total_tokens,
            SUM(l.quota) as total_quota,
            COUNT(DISTINCT el.subject_id) as subject_count,
            COUNT(DISTINCT el.teacher_id) as teacher_count
        FROM 
            school_mappings sm
        LEFT JOIN 
            extended_logs el ON sm.school_id = el.school_id
        LEFT JOIN 
            logs l ON el.log_id = l.id
        WHERE 
            l.created_at BETWEEN ? AND ?
        GROUP BY 
            sm.school_id, sm.name
        ORDER BY 
            total_quota DESC
    `
    
    err := DB.WithContext(ctx).Raw(query, startTime, endTime).Scan(&stats).Error
    return stats, err
}
```
